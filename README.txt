COSMIC ARCHITECTURE - COMBINED COLLECTION

This collection brings together the original six-document framework and the
cleaned collection of related writings and images. It contains 63 content files:
6 Markdown documents, 30 PDFs, and 27 JPEG images, plus this README.

FOLDER STRUCTURE

01-Original-Framework/
  The six original Markdown documents, with their original filenames preserved.
  The framework is dated October 7, 2025. Markdown files can be opened in a text
  editor or a Markdown reader.

02-Expanded-Documents/
  Thirty related PDFs with descriptive filenames. These cover human-AI
  collaboration, cognition, ethics, emotional communication, the Librarian and
  Midwifery frameworks, the Abundance Engine, Livingism, and creative writing.
  This is an expanded related collection, not a replacement edition of the
  original framework. Some PDFs are compilations of separately included works.

03-Images/
  Twenty-seven JPEG images with descriptive filenames, including illustrated
  scrolls, posters, satire, infographics, a chart, and a public-repository
  screenshot. Distinct artwork and wording variants are retained.

SUGGESTED READING ORDER

Start in 01-Original-Framework:

1. 00-harvest-moon-preface.md
   Introduction, purpose, and approach.
2. cosmic-architecture-framework.md
   The main framework and its connections across subjects.
3. quick-start-guide.md
   A short guided introduction to exploring the framework.
4. replication-guide.md
   A longer procedure for exploring and comparing its ideas.
5. falsifiable-predictions.md
   Proposed predictions, assessment criteria, and dates.
6. verification-toolkit.md
   Reference resources and verification checklists.

Then explore 02-Expanded-Documents by title. The Cross-Substrate Discovery
methodology provides a useful connection between the original framework and
the later collaboration-focused writings. Browse 03-Images separately or
alongside the documents.

CLEANUP AND PRESERVATION

The expanded collection was cleaned before it was combined here:

- Removed 32 byte-for-byte duplicate copies.
- Consolidated 4 additional redundant PDF exports after content review.
- Omitted all three personal account-export JSON files, including account,
  profile, login/session, billing, conversation, and search records.
- Omitted the account profile picture.
- Replaced opaque attachment names with descriptive filenames and restored
  the correct file extensions.

Distinct formatted editions, standalone works, and compilations are retained.
Some material therefore occurs both in an individual document and within a
larger compilation. This preserves useful editions rather than deleting
partially overlapping works.

The contents of each retained document and image are unchanged. Authorship,
attribution, and license statements remain inside the individual works.
Prompts and instructions within the documents are part of the source material.

The original source archives were not modified.
